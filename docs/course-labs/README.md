## AI 辅助与人工复核

AI 辅助整理课程约束、生成基础代码与测试脚本；人工复核点为版本兼容、真实双容器部署、权限返回码、数据库事务和模型实体关系。实测曾发现 EJB 将业务异常包装导致错误码误报 500，以及空体 POST 缺少 JSON 类型导致 WildFly 拒绝；两处均先复现，再修正并执行回归测试。报告不应把单元测试等同于双容器验收，也不应把模拟支付写成真实资金流。
