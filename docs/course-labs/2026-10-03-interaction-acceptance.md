本轮完成已确认的三项：挂号目录下拉、完成预约的病历账单快捷入口、筛选重置与导航高亮。沿用 Java 8 → Tomcat 9 JSP/Servlet → WildFly 10 EJB/JAX-RS → JNDI/JPA → MySQL；未修改原 Java 21/Vue 实现、数据库结构、既有业务行或 70 台 IaaS 逻辑模型。

## 功能

- 新增公开只读目录：医院、按医院筛选科室、按医院及可选科室筛选医生。只返回 `id/name`，排除停用机构/科室/医生、非医生角色及机构或科室关联不匹配的医生，不暴露账号、密钥或医疗信息。
- 患者以医院—科室—医生下拉选择替代手填编号；号源行显示科室、医生名称。医院切换清空科室和医生，科室切换清空医生；GET 刷新选项不写入数据库，也不自动预约。
- 无脚本时通过“更新选项”刷新下级目录。只有显式目录刷新才使用上一次选择来清空下级；普通查询必须校验当前下级归属，不能因伪造的上次选择而扩大查询范围。
- 仅已完成预约显示“查看病历与账单”。快捷链接编码预约 ID、转义 URL，保留医院/科室/医生/日期并定位病历区域；手动病历查询也保留这四项。权限仍由既有本人病历/订单接口校验。
- 患者、医生、医院筛选提供重置链接、保留查询区域定位并增加提示。外部小脚本为当前导航设置 `aria-current="location"`，支持点击、锚点、手动滚动及短末尾卡片；没有脚本仍可使用锚点导航。
- 目录、预约历史和选中病历独立读取，目录服务失败时不隐藏已经能读取的历史与病历。未改动预约、接诊、缴费 POST 契约及 CSRF 机制。
