# 课程版门户 UI 验收（2026-10-02）

本次仅改进课程版 JSP 门户的展示及静态资源加载，沿用 Java 8、Tomcat 9、WildFly 10、JNDI/JPA 和 MySQL。业务接口、角色权限、数据库结构与独立 Vue 前端不变；没有执行数据库迁移或新增诊疗场景。

## 页面与交互

- 登录与患者注册：品牌介绍和表单分栏；小屏改为上下布局；始终保留课堂演示提示。
- 患者、医生、医院及平台：统一工作台导航、账号栏、内容卡片和空状态。导航定位本页功能区，不显示未实现功能。
- 预约、支付、账号和号源状态：中文标签与不同颜色配合，不仅依靠颜色表达含义。英文状态码仍在标签提示中保留。
- 医院编辑表单：使用原生 `details/summary` 展开，不依赖 JavaScript；原有提交地址、字段、隐藏 ID 和 CSRF 保留。
- 长编号可换行；八个表格容器均可用键盘聚焦，在小屏内横向滚动，有区域名称和可见焦点边框。
- 平台页修正服务分层说明：MySQL 属于 PaaS 数据服务；IaaS 是计算、网络、存储和虚拟化，70 台服务器仍仅为逻辑模型。

## 验证证据

1. 开发前全量测试基线通过。新增六项真实 Jasper 渲染测试先失败后通过，覆盖登录/注册、三个角色工作台和平台说明。
2. 浏览器发现静态资源请求被 `PortalServlet` 的 `/` 默认映射拦截。专项测试复现 CSS 返回 404；新增 `WEB-INF/web.xml` 将 `/assets/*` 映射至 Tomcat 继承的 default servlet 后返回 200、`text/css`，业务路由及注解扫描不变。
3. 键盘表格区域专项先失败后通过。所有新 UI 测试共八项，另有既有历史支付时间 JSP 回归保持通过。测试样本含可预约号源、接诊中表单、完整病历、长编号和转义文本。
4. 最终 `mvn -f course/pom.xml clean verify` 成功：共 84 项，83 项通过，0 失败/错误；1 项临时 MySQL 专项因本轮未启动专项环境而跳过。其先前实际运行证据见 [P0 验收](2026-10-02-p0-acceptance.md)，本记录不将先前结果充作本轮运行。
5. 已部署门户至 Tomcat 9.0.24 的 `http://127.0.0.1:8188/portal/login`。登录页、注册页、WildFly 目录接口和 CSS 均返回 200；CSS 类型为 `text/css`。上一版门户 WAR 已在隔离运行目录备份。
6. 真实浏览器登录 `patient_demo`、`doctor_a`、`hospital_a`，页面均正常生成，无公共错误提示；检查科室编辑面板展开以及医院 `PAID` 账单筛选，未提交修改数据的表单。
7. 目视检查登录、注册及三个角色桌面页；在 390×844 视口检查患者、医生、医院和注册页。医院账单区域获得键盘焦点后，右方向键使 `scrollLeft` 达到 40，焦点轮廓为 solid；表格横向溢出留在容器内。
