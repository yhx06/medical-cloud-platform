# 课程演示冒烟测试

1. 打开登录页，使用错误密码，确认显示中文错误且没有进入工作台。
2. 使用 `patient_demo` 登录，确认仅显示工作台、我的预约、诊疗记录与订单。
3. 使用 `doctor_a` 登录，访问医院资料接口，确认医院为“仁和云诊所”。
4. 使用 `doctor_b` 登录，确认医院为“安康云门诊”，且不能访问租户 A 的对象。
5. 使用 `hospital_a` 登录，确认可以进入医院管理工作区。
6. 使用 `platform_admin` 登录，确认租户列表同时显示两个租户，但没有诊疗记录入口。
7. 无令牌访问 `/api/me` 应返回 401；角色不匹配的接口应返回 403；响应均带 `X-Request-Id`。
8. 访问 `/actuator/health`，确认返回 `UP`。

答辩时建议按“患者预约 → 医生接诊 → 医院管理 → 平台多租户视角”的顺序讲解，并明确基础版本与后续业务范围的边界。
